# MathBridge CN Data Architecture

## Core principle

MathBridge does not store isolated articles. It stores mathematical concepts and maps how different education systems teach those concepts.

## Data flow

Concept → Curriculum Expectation → Teaching Method → Classroom Example → Source Evidence

## Initial systems

- China: Ministry of Education curriculum standards and textbook pathways
- England: National Curriculum, DfE guidance, NCETM mastery resources
- United States: Common Core and selected state frameworks

## Main entities

- Countries
- Curriculum frameworks
- Grades
- Grade equivalency mappings
- Mathematical domains
- Mathematical concepts
- Curriculum expectations
- Teaching methods
- Lesson examples
- Sources

## Future expansion

This structure supports:

- teacher search
- curriculum comparison
- AI explanations
- lesson planning recommendations
- professional development content
- evidence-linked answers
